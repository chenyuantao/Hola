# Hola · 言好 Logo 探索

根据 Sources/main.swift 的当前实现，产品是 macOS 菜单栏文字润色助手，重点是保持原意、改善语气与流畅度。仓库主 README 仍描述早期 AX 测试工具，设计以源码为依据。

使用 logo-generator Skill 的几何 / 线条 / 字母抽象设计流程，按用户要求交付五款。展示页沿用 Skill 的卡片比较方式，改为无外部依赖的离线页面。

## 1. 开口即好

把小写 h 的肩部延展成对话尾巴。Hola 的首字母成为一个正在开口的符号，轻松、友好，也适合独立作应用图标。

主色：#D36148。文件：`01-hola.svg`、`01-hola-color.svg`、`01-hola.png`。

## 2. 言之有意

从「言」字提取点、横与口：上方是表达，下方是承载原意的开口。中文辨识最强，呈现克制、可信的编辑气质。

主色：#346B57。文件：`02-yan.svg`、`02-yan-color.svg`、`02-yan.png`。

## 3. 让意思舒展

同一条带子由紧凑的回环舒展成开放的弧线：意思仍是你的，表达变得从容。抽象、有动感，适合建立独立品牌。

主色：#5265A4。文件：`03-unfold.svg`、`03-unfold-color.svg`、`03-unfold.png`。

## 4. 本意生花

两枚引号像种子展开的叶片，中间的留白保留生长空间。将文字、原意与更好的表达联系起来，柔和而有人文感。

主色：#A66730。文件：`04-seed.svg`、`04-seed-color.svg`、`04-seed.png`。

## 5. 话有所应

两道相向的括弧，围住一颗不变的原点。原点代表你的意思，括弧代表更妥帖的表达与接收；简洁、安静、易缩放。

主色：#986078。文件：`05-resonance.svg`、`05-resonance-color.svg`、`05-resonance.png`。

打开 index.html 比较品牌色、单色和深色，以及 16 / 24 / 40 px 缩略。小尺寸为浏览器预览，尚未集成 macOS 状态栏实测。图案为可编辑 SVG，PNG 由 rsvg-convert 渲染。此阶段未调用生成式图像服务；选定方向后再制作应用图标或展示图。

## 本轮品牌简报

品牌：Hola · 言好。标语：你的意思，更好的表达。
设计主张：保留本意，让表达更自然。上一轮设计保留在 ../logo-concepts。
每款新增 -lockup.svg / -lockup.png 品牌组合。组合 SVG 的字标使用系统字体，未转曲；独立符号完全由矢量路径构成。
重新生成：先运行 generate.py，再运行 board.py。
