# 手工验收

在 macOS 上用非敏感文本测试，并记录系统版本、目标应用版本及输入法。

| 场景 | 预期 |
| --- | --- |
| 拖入多个 `.app`、移除其中一个 | 只在保留的应用中拦截；重启后列表仍在 |
| 导出后导入配置 | 应用列表、Jev 开关及接口设置恢复 |
| Jev 关闭，OpenAI 成功 | 每次调用 OpenAI；结果相同则发送，有变化则回填并等待确认 |
| Jev 开启，判断无需润色 | 不调用 OpenAI，发送原文 |
| Jev 或 OpenAI 超时、HTTP 错误、空响应 | 不发送；显示失败，可再次回车重试 |
| 调用期间切到另一所选应用或输入框 | 不写入或发送到新焦点 |
| 回填后切换应用、输入框或修改文本 | 旧结果不能直接确认发送 |
| 输入框为空，或只有空格、换行时按回车 | 原样放行；不触发润色请求 |
| 输入框只有图片等嵌入对象，没有文字时按回车 | 原样放行，不触发润色请求，图片仍在 |
| 输入框有图片等嵌入对象及文字，模型只改文字 | 嵌入对象保持原样，只有文字被回填；再次回车可发送 |
| 模型删除、重排或改写 `<object id="…">` | 保留原草稿，不回填、不发送，提示占位符异常 |
| 输入框有嵌入对象但不支持局部文字写回 | 保留原草稿，不发送，提示写回失败 |
| 密码框、非文本控件、AX 读取失败 | 不读取敏感值，不把回车作为成功处理 |
| 普通输入法组词、带修饰键回车 | 保持目标应用原有行为 |
| 设置面板的单行输入框和多行提示词 | Cmd+A/C/X/V、Cmd+Z、Cmd+Shift+Z 均可编辑当前焦点文本 |

## 品牌升级

- 首次启动 Hola，确认旧版目标应用与接口设置已迁移；不要在记录中暴露 Token。
- 确认旧调用历史可见，旧文件仍保留。
- 修改 Hola 配置并重新启动，确认不会被旧配置覆盖。
- 导出配置的文件名应为 `hola-settings.json`，格式标识为 `hola-settings`；旧版配置文件仍可导入。
- 为 Hola 重新授权，验证开启、回车润色与确认发送。

## 启动与状态恢复

- 首次启动且未开启时，菜单栏图标右下角显示黄色圆点。
- 配好权限、OpenAI 和目标应用后开启拦截：黄色圆点消失；退出再打开，底部拦截开关为开启，无需手动打开即可处理回车。缺权限、OpenAI 或目标应用时开关不可用，悬停可看到原因。
- 手动停止后退出再打开：保持未开启并显示黄色圆点。
- 上次开启后撤销辅助功能权限再打开：不弹窗、不拦截键盘，状态说明权限缺失并显示黄色圆点；重新授权后可手动开启。
- 开启自动恢复但目标应用列表为空：保持未开启，状态说明目标应用未配置。
- macOS 13+ 在通用页勾选开机启动后，系统登录项中出现 Hola；注销再登录验证启动与开启恢复。
- 取消勾选后，系统登录项不再自动启动 Hola。勾选会立即注册；关闭面板不回退已经生效的登录项。
- 系统要求批准登录项时，显示提示并打开系统设置；注册失败时保留设置窗口并显示错误。
- macOS 12：自启动开关不可用，显示手动添加登录项的指引。
- 运行中的绿点、红点与加载动画保持正常；无论此前结果如何，停止后始终显示黄色圆点。

## 中英双语

| 场景 | 预期 |
| --- | --- |
| 中文系统或 Hola 首选语言设为中文，重新打开 | 菜单、设置、状态、错误和历史界面为简体中文 |
| 英语系统或 Hola 首选语言设为英文，重新打开 | 对应界面为英文，设置按钮和表头布局正常 |
| 首选语言为繁体中文、香港或台湾地区中文 | 使用简体中文资源 |
| 首选语言为法语等未支持语言 | 回退到英文 |
| 切换语言后打开历史 | 表头与结果状态使用新语言；原文、用户提示词及已记录的处理说明不被改写 |
| 英文界面润色中文草稿，或中文界面润色英文草稿 | 默认提示词要求保留草稿语言；需使用真实模型核验效果 |
| 配置自定义提示词后切换系统语言 | 自定义配置不被默认提示词覆盖 |
| 导入、导出及权限错误 | 提示文字符合当前界面语言，文件格式和 Token 不受语言影响 |

自动检查：先执行 `bash build.sh`，再执行 `bash scripts/test-localization.sh`。

### Apps 与界面语言配置

- 在面板中增删 Apps 后导出；导入该文件后确认名称、Bundle ID、路径和列表顺序一致。空列表应能清空现有 Apps。
- 将界面语言设为 English 或简体中文，确认面板各分区立即更新；重启后保持选择。
- 未设置语言或选择“跟随系统”时，继续按系统首选语言判断（中文变体使用简体中文，其余使用英文）。切换语言立即生效。
- 导出并导入语言设置，确认立即生效；导入不含语言或 Apps 的旧配置时，已有值不变。
- 导入 Apps JSON 损坏、Bundle ID 缺失/重复或语言值非法的文件，确认提示失败且不修改任何设置。

自动回归：`bash scripts/test-settings.sh`、`bash scripts/test-localization.sh`（后者需先构建）。
